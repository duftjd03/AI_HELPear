방법 1: 로컬 파일 업로드 (✅ 권장)
  1-1. 파일 선택 버튼으로 PC의 동영상/음성 파일 선택
  1-2. 재생 후 "🎯 분석 시작" 클릭
방법 2: 일반 비디오 URL (MP4/WebM)
  2-1. URL 입력 후 "영상 로드" 클릭
  2-2. "🎯 분석 시작" 클릭
방법 3: 탭 오디오 직접 캡처 (어떤 사이트든 가능)
  3-1. 원하는 사이트에서 재생
